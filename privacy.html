Vidura - Privacy Policy

Last updated 20 September 2026

Who this covers

Vidura is a private application operated by a single individual for personal use. It has one user - its operator - and is not available to anyone else. This policy describes what it does with Google account data so that Google's requirements for connected applications are met.

What Google data it accesses

Vidura connects to exactly one Google account, which belongs to and was created by its operator solely for this purpose. It requests read-only access to that account's Gmail mailbox (the gmail.readonly scope). It cannot send, reply to, delete, archive, label or otherwise change any message.

How the data is used

Messages and attachments are read so that the operator's own assistant can file and summarise them for the operator. The data is used for no other purpose.

Where the data is stored

Everything Vidura reads is stored on the operator's own computer. Nothing is uploaded to any server operated by Vidura, and nothing is stored in the cloud by Vidura.

Sharing

No Google user data is shared with, sold to, or transferred to any third party. It is not used for advertising. It is not used to train machine-learning models. No human other than the operator reads it.

Retention and deletion

Data remains on the operator's computer until the operator deletes it. Access to the Google account can be revoked at any time from the account's security settings at myaccount.google.com/permissions, after which Vidura can read nothing further.

Google API Services User Data Policy

Vidura's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
